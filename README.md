# Sunskip

> Пастельный 3D-раннер над крошечной луной Нектар. Ты курьер на маленьком кораблике: скользишь над дюнами, пролетаешь впритирку к препятствиям ради комбо, собираешь кристаллы и бьёшь рекорд, а сутки на луне длятся всего 3000 метров.

## Геймплей

Бесконечный раннер со сменой времени суток прямо во время забега: рассвет → полдень → закат → восход луны. Облетай гряды, «брей» препятствия ради очков, собирай осколки и открывай новые корабли.

### Управление

| | Клавиатура | Телефон |
|---|---|---|
| Руль | `←` / `→` или `A` / `D` | вести пальцем |
| Прыжок | `Пробел` | тап |
| Бочка сквозь препятствие | `Shift` | свайп вниз |
| Пауза | `P` / `Esc` | — |
| Режим записи 9:16 | `C` | — |

Поддерживается геймпад.

## Что внутри

- **Два режима.** «Свободный полёт» и «Ежедневный забег»: у всех одинаковый сид на дату, а рядом летит призрак твоей лучшей попытки. Плюс ежедневные миссии с наградами.
- **Комбо-система.** GRAZE / PERFECT / SKIM / RING / SMASH и режим FEVER. Бонусы «Магнит», «Щит» и «Комета», метеоритный дождь с метками на земле, «второй шанс» после аварии.
- **Ангар и прогресс.** 5 кораблей за осколки (Paper Kite, Mint Julep, Lilac Moth, Coral Comet, Golden Hour), журнал пилота со статистикой и значками.
- **Визуал.** Шейдер «изогнутого горизонта», небо по зонам времени суток, частицы и обломки. Качество подстраивается под FPS.
- **Процедурный звук.** Музыка ускоряется вместе с игрой, звуковые эффекты синтезируются через Web Audio.
- **Для соцсетей.** Фоторежим с фильтрами, режим записи 9:16, PNG-карточка результата 1080×1350 и копирование текста результата.
- Сохранение прогресса в localStorage, RU/EN, вибрация на Android.

## Структура

```
src/
  body.html     — разметка
  style.css     — стили
  js/00-util.js … 09-main.js — логика игры по модулям
build.mjs       — собирает src/ в один index.html (без зависимостей)
index.html      — готовая страница
```

## Запуск

```bash
node build.mjs   # пересобрать index.html из src/
```

После этого открыть `index.html` в браузере; нужен интернет, потому что Three.js грузится с CDN. `npm install` не нужен: сборщик использует только встроенные модули Node.

> Общий лидерборд работает только в рантайме claude.ai-артефактов (`dist/artifact.html`, генерируется той же командой). Локально показываются лучшие забеги на этом устройстве.
